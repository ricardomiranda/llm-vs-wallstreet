# Security policy

## Reporting a vulnerability

Use the repository's **Security** tab and **Report a vulnerability** option to
send a private report when that feature is available. If private vulnerability
reporting is unavailable, contact the repository maintainer through their
GitHub profile before disclosing the issue publicly.

Do not include brokerage statements, account identifiers, portfolio databases,
generated plans, credentials, or other private financial data in security
reports, issues, or pull requests.

## Private portfolio data

Broker exports, local portfolio databases, generated buy plans, and credentials
are user-local data. They are ignored by Git and must not be added to commits,
issues, pull requests, logs, or CI artifacts.
